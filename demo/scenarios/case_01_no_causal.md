# Сценарий: `case_01_no_causal` — удалён причинный вариант

**Вход:** модифицированный case_01, 405 вариантов, 15 HPO «+», 6 HPO «−», модификация: да (`dataset_modification = causal_variant_removed_for_abstention_demo`). Из TSV и VCF удалён `chr15:48412568:C:A`; `variant_count` уменьшен 406 → 405.

**Ожидаемый статус по ТЗ-2.3:** проверить фактически; допустимы `uncertain` или `candidate`.
**Фактический статус:** `candidate`.

**Числа:** top-1 SMAD3 / ORPHA:91387, балл 0.490; FBN1 в выдаче отсутствует; причинный вариант удалён из входа.

**Что говорим (2–3 фразы):** «Причинный вариант удалён, но система выбрала фоновый вариант SMAD3 из GIAB, а не заявила отсутствие причины. Это честный отрицательный результат демонстрации: удаление одного варианта само по себе не гарантирует отказ, потому что в фоновом геноме есть редкие варианты в болезненных генах. Сценарий нельзя выдавать за `no_convincing_candidate`; для демонстрации отказа используем `incomplete_demo`».

**Чего не хватает для проверки:** независимой курации фоновых вариантов, семейного анамнеза, фазы, условия «нет причинного варианта» на уровне лабораторного подтверждения.

**Ограничение:** модифицированный набор — не случай организаторов; benchmark/evaluate на нём не запускались. Пометка есть в метаданных, `README_MODIFIED.md` и предупреждении отчёта.
