# Подключение GigaChat-2-Pro

Выбранная модель: **`GigaChat-2-Pro`**. Роль — выбирать доказательства для объяснения уже рассчитанного рейтинга. Модель не меняет порядок кандидатов и баллы. Используем личный проект с `scope=GIGACHAT_API_PERS`.

На присланном скриншоте указан тариф Pro: 40 млн токенов на 12 месяцев. Скриншот тарифной таблицы сам по себе не подтверждает остаток или активацию квоты конкретного проекта. Проверить их можно в кабинете; код не покупает пакеты.

## Настройка ключа

1. В настройках своего проекта GigaChat API получите **ключ авторизации / Authorization Key**. Это исходный ключ для OAuth, а не короткоживущий access token. Не публикуйте его в чате или репозитории.
2. Откройте PowerShell в папке проекта и запустите:

```powershell
.\setup-gigachat.ps1
```

3. Вставьте ключ в скрытое поле терминала. Скрипт сохранит его в `.secrets/gigachat.dpapi`, зашифрованном Windows DPAPI для текущего пользователя. Папка исключена через `.gitignore`. Этот файл нельзя переносить другому пользователю или на другой компьютер как рабочий ключ.
4. Сначала проверьте доступ и JSON-схему на полностью вымышленном примере без геномных и фенотипических данных:

```powershell
.\run.ps1 llm-check --synthetic
```

Команда проверит наличие `GigaChat-2-Pro` в списке доступных моделей, выполнит один запрос и проверит ответ guard. При успехе будет создан `outputs/llm_check.json`. Ключ и токен доступа в него не записываются. Это живой запрос, он расходует доступные токены. Для проверки учебного `case_01` отдельно используется `--report outputs/demo/case_01.json`; в API отправляются сведения о трёх верхних кандидатах и их доказательства, а не весь файл отчёта.

5. После успешной проверки:

```powershell
.\run.ps1 run --case case_01 --llm --output outputs/gigachat_demo
```

Без `--llm` отчёт по-прежнему формируется локально из шаблона. Если LLM недоступна или результат отклонён guard, отчёт укажет переход на шаблон.

## Переменные окружения

Значения по умолчанию:

```text
GENOMIC_LLM_PROVIDER=gigachat
GENOMIC_LLM_MODEL=GigaChat-2-Pro
GIGACHAT_SCOPE=GIGACHAT_API_PERS
```

При запуске напрямую через Python можно задать `GIGACHAT_CREDENTIALS` в окружении процесса. Автоматическое чтение DPAPI-файла реализовано в `run.ps1`. Никакие `.env`-файлы автоматически не загружаются.

Для краткого теста поддерживается `GIGACHAT_ACCESS_TOKEN`. Скопированный временный токен истекает; для обычной работы используйте ключ авторизации. При использовании ключа адаптер получает OAuth-токен, держит его только в памяти и обновляет по сроку действия.

## Адреса и TLS

- OAuth: `https://ngw.devices.sberbank.ru:9443/api/v2/oauth`.
- API: `https://api.giga.chat/v1`.
- Генерация: `POST /chat/completions`, `response_format.type=json_schema`, `strict=true`.

Проверка TLS включена. В проект добавлен `config/certs/gigachat-ca.pem`: официальные корневой и выпускающий сертификаты с Госуслуг, загруженные по проверенному HTTPS. Адаптер GigaChat автоматически использует этот файл только для своих запросов. Системное хранилище Windows и соединения Ensembl не меняются. Адреса загрузки и SHA-256 записаны в `config/certs/sources.json`.

Можно явно задать `GIGACHAT_CA_FILE` — путь к другому доверенному PEM-файлу CA. Адаптер не отключает проверку сертификатов. Для повторного получения официальных сертификатов подготовлен `scripts/fetch_gigachat_certificates.py`; `scripts/check_gigachat_network.py` проверяет транспорт без чтения и отправки ключей.

## Проверенный объём

Автотесты проверяют OAuth-заголовки, миллисекунды/срок токена, повторное использование и обновление токена, формат запроса Pro, разбор JSON, guard, отказ при обрезанном ответе и сетевые ошибки без раскрытия секретов. Для установленного локально ключа подтверждён живой запрос `GigaChat-2-Pro` на искусственном JSON-примере: подключение и guard прошли. Подробные результаты конкретных проверок сохраняются в `outputs/gigachat_*_check.json`.

Официальные источники: [авторизация](https://developers.sber.ru/docs/ru/gigachat/api/reference/rest/gigachat-api), [структурированный ответ](https://developers.sber.ru/docs/ru/gigachat/guides/structured-output), [тарифы](https://developers.sber.ru/docs/ru/gigachat/tariffs/individual-tariffs).
