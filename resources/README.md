# Данные для запуска из репозитория

`validation-pilot-v1.zip` — замороженные входы внешнего полусинтетического пилота на 20 опубликованных случаях, единый синтетический фон, отдельные ответы и журнал отбора, VEP/ClinVar-снимки. Готовые рейтинги не включены. SHA-256 архива и всех членов — в `validation-pilot-v1.manifest.json`. Лицензия Phenopacket Store: `phenopacket-store-LICENSE`. Сборка сопровождающим: `python scripts/build_validation_bundle.py`. [Методика, результаты и офлайн-повторение](../docs/validation_results_v1.md).

`clinvar-snapshot.json` — отдельный нормализованный снимок NCBI ClinVar от 12 ноября 2026 года для 114 вариантов учебного набора, имеющих клинические отметки VEP. Хранятся точные аллели GRCh38, germline RCV, условия применимости, review status/дата и ссылки; хеши исходных XML и параметры получения включены в снимок. Это не полная база ClinVar. Обновление сопровождающим: `python scripts/fetch_clinvar.py`; обычный интерфейс использует локальный файл без сети. SHA-256 снимка записывается в каждый отчёт v1.2.

`python-3.14.10-embed-amd64.zip` — неизменённый официальный embeddable runtime Python для Windows x64. SHA-256 из python.org закреплён в `config/python-runtime.json`; оригинальная лицензия Python находится внутри ZIP. Нужен для запуска без установленного Python и без интернета. Другие архитектуры при необходимости получают официальный runtime автоматически по тому же манифесту.

`demo-data.zip` — локальный снимок от 12 ноября 2026 года. Размер около 10 МБ, после распаковки около 90 МБ. Он содержит:

- VEP-кэш для 3 690 уникальных вариантов учебного набора, покрывающий 4 096 строк десяти случаев; Ensembl release 116, GRCh38.
- Исходные файлы HPO: `hp.obo`, `genes_to_phenotype.txt`, `phenotype.hpoa` и манифест их получения. Версия онтологии — 2026-09-01, заголовок phenotype.hpoa — 2026-09-02.

При запуске `serve` недостающие файлы восстанавливаются в `data/cache/` и `data/knowledge/`. SHA-256 архива и отдельных файлов записаны в `demo-data.manifest.json`. Полный пользовательский кэш не перезаписывается; незавершённые справочники другой версии не смешиваются со снимком.

Это исходные аннотации и справочники: готовых рейтингов, ключей API и данных из `.secrets` в архиве нет. Рейтинг для каждого запроса рассчитывается заново; при изменении HPO используются тот же набор вариантов и текущие правила.

Происхождение, ссылки и благодарности: [docs/data_sources.md](../docs/data_sources.md). Файлы HPO внутри архива сохранены без изменения содержимого. Рабочая распаковка и результаты исключены из Git.

Для сопровождающего проекта: снимок собирается из подготовленных локальных данных командой `python scripts/build_demo_bundle.py`. Скрипт использует SQLite backup API и фиксирует хеши. После обновления данных нужно обновить архив и манифест вместе и повторить проверку чистого запуска.
