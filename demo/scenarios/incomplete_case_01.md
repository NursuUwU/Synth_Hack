# Сценарий: `incomplete_demo` — отсутствует аннотация

**Вход:** case_01, 406 вариантов, 15 HPO «+», 6 HPO «−», модификация: копия кэша без одной аннотации (`GRCh38:chr15:48412568:C:A`), исходный архив не изменялся.

**Ожидаемый статус:** `incomplete`, prediction = None, `predictions.partial.tsv`, код возврата 2.
**Фактический статус:** `incomplete`, prediction = None, coverage = 99.75 % (405/406), код возврата 2.

**Что говорим (2–3 фразы):** «Не хватает одной аннотации, поэтому система не выдаёт ответ и не называет отсутствие причины доказанным. Это режим `incomplete`: данных для завершённого вывода недостаточно, а не “причины нет”. Полный `predictions.tsv` в таком прогоне не формируется — только `predictions.partial.tsv`».

**Чего не хватает для проверки:** восстановить аннотацию варианта, проверить покрытие 100 %, семейный анамнез и фазу.

**Ограничение:** `incomplete` — про данные, а не про биологию; отсутствие аннотации не является доброкачественным свидетельством.
