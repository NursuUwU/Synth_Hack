# Локальный интерфейс

**Windows:** скачать репозиторий, полностью распаковать ZIP, дважды нажать `Start.cmd`. В PowerShell можно выполнить `.\start.ps1`. Установленный Python 3.11+ используется автоматически; при его отсутствии на Windows x64 лаунчер распакует официальный переносимый Python из репозитория в папку проекта. Интернет и API-ключ не нужны. На Windows ARM64/32-bit без Python подходящий runtime скачивается с python.org.

**macOS / Linux:** при установленном Python 3.11+ выполнить `sh start.sh` из папки проекта. Для прямого запуска на любой ОС: `python -m genomic_detective serve --open`.

После загрузки справочников сервер напечатает `Local UI: http://127.0.0.1:8765`. При первом запуске загрузка HPO может занять несколько десятков секунд. Остановка — `Ctrl+C`. Если порт занят, добавьте `--port 8766`. Без `--open` браузер нужно открыть вручную.

Терминал с этой командой нужно оставлять открытым во время работы: вкладка браузера сама сервер не запускает. Если появляется сообщение о недоступном сервере (раньше — `Failed to fetch`), запустите команду заново, дождитесь `Local UI` и обновите вкладку (`F5`). Обновление также нужно после перезапуска сервера, чтобы получить новый токен рабочей области.

Внешние Python-пакеты не нужны. Исходный ZIP и `resources/demo-data.zip` включены в репозиторий. На чистом компьютере команда serve сама распаковывает аннотации и HPO в data/, сверяя SHA-256. Команда prepare для демонстрации не требуется; она нужна для нового получения или обновления справочников и аннотаций. Происхождение снимка: [data_sources.md](data_sources.md).

Windows-лаунчер запускает только свой PowerShell-процесс с разрешением исполнения скриптов проекта; системная политика, PATH и реестр не меняются. Если организационная политика запрещает скрипты, используйте установленный Python и прямую команду выше. Приложение не отменяет такие ограничения.

## Что доступно

- Выбор любого из десяти случаев; открытые ответы в интерфейс и расчёт не загружаются.
- Изменение HPO-профиля: «Есть», «Нет» (явно отсутствует), «−» (не учитывать).
- Поиск нового признака по HPO ID или английскому названию из локальной онтологии.
- Рейтинг с итоговым баллом и оценками трёх экспертов; первые 10 строк, раскрытие до 50. Все варианты есть в TSV и полном отчёте.
- Серо-голубая строка с меткой «Просмотр» означает открытую карточку. При статусе «Конкурирующие гипотезы» все варианты с разрывом менее 0.025 от первого отмечены янтарным и меткой «Близкий балл»; сводная карточка показывает их количество вместо одного ведущего гена. Группа рассчитывается по всем вариантам, поэтому её размер может превышать 50 видимых строк. Это тот же эвристический порог разрыва, который использует конвейер, без новой оценки достоверности. Совпадение баллов не означает равную вероятность заболевания.
- Изменение позиции относительно предыдущего расчёта того же случая. «—» означает, что сравнения нет (в том числе если вариант отсутствовал в предыдущих первых 50), «·» — позиция та же.
- Выбор строки для просмотра фенотипических совпадений, противоречий, молекулярных аннотаций, наследования, источников и недостающих данных. Курируемое точное литературное свидетельство показывается отдельно с меткой «Литература», `LIT:<id>`, PMID и границами применимости; VEP-класс при этом не переписывается.
- Отдельные состояния: исследовательский кандидат, конкурирующие гипотезы, требуется проверка доказательств, недостаточно данных, убедительный кандидат не выделен. Ограниченная молекулярная поддержка не изображается как близость баллов.
- Скачивание HTML, JSON и полного рейтинга TSV. Запуски сохраняются отдельно в `outputs/ui/<run_id>/`; оригинальный набор не изменяется. Ссылки скачивания доступны до остановки текущего сервера, файлы остаются на диске.

При редактировании признаков старый результат скрывается до пересчёта. «Восстановить» возвращает исходный профиль; после этого также нужен пересчёт.

## Сценарий демонстрации

1. Выбрать случай 01, нажать «Рассчитать рейтинг»: FBN1 занимает первую позицию, балл v1.2 около 0.651. Показать отдельную оговорку об ограниченной молекулярной поддержке.
2. Изменить Retrognathia с «Есть» на «Нет» и пересчитать. Показать изменение фенотипической оценки и противоречие в карточке FBN1. Это интерактивный эксперимент с признаками, а не новый клинический случай.
3. Восстановить исходный профиль и пересчитать.
4. Выбрать случай 05: LMNA теперь первый, балл около 0.703. Открыть карточку: `synonymous_variant` сохранён, отдельно показаны точный опубликованный сплайсинговый эффект (`LIT:lmna_g608g_splice`, PMID 12714972), crosswalk `ORPHA:740 ↔ OMIM:176670` по Orphadata и ClinVar с заболеванием/review status. Источники кликабельны; поддержка объединяется через `max()`, не суммируется повторно.
5. Скачать отчёт или TSV для проверки вне приложения.

## Устройство

`genomic_detective/web.py` — стандартный `ThreadingHTTPServer`, слушает только `127.0.0.1`. Статические HTML/CSS/JS находятся в `genomic_detective/static/`. POST `/api/analyze` вызывает исходный `Pipeline` с `offline=True`, без LLM; расчёт выполняется заново для всех вариантов. Готовые ответы из `outputs/demo` не подставляются. Веб-интерфейс не меняет правила ранжирования.

Обработка одного анализа за раз; конфликтующие параллельные запуски получают сообщение о занятости. SQLite-соединение создаётся в потоке запроса. Изменённые профили помечаются `phenotype_override=interactive_ui`, что исключает их из обычной оценки открытых ответов. Проверяются Host, Origin, токен текущей рабочей области и размер запроса. Произвольные файлы проекта и секреты сервер не раздаёт. Данные интерфейса вставляются как текст, без интерпретации HTML.

LLM-подбор объяснений остаётся доступен через существующую CLI-команду `run --llm`; эта версия интерфейса работает полностью локально. Баллы не являются вероятностями диагноза; механические guards проверяют целостность расчёта, а не клиническую достоверность.
