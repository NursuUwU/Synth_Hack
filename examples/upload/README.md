# Пример для проверки загрузки своего случая

Файлы для кнопки «+ Загрузить свой случай (VCF)»:

- `kbg_ankrd11.vcf` — VCF пробанда, GRCh38, один образец. 400 SNV случая `external_07` внешнего пилота (опубликованный случай синдрома KBG, ген ANKRD11; Phenopacket Store 0.1.27, PMID 36446582, лицензия BSD-3-Clause — `resources/phenopacket-store-LICENSE`) на искусственном фоне, плюс:
  - 2 межгенных SNV на chr16 (60000000, 60000500), которых нет в локальном кэше, — для проверки онлайн-аннотации;
  - 4 строки, которые должны быть пропущены: индел, мультиаллельная, генотип 0/0, FILTER=LowQual.
- `kbg_ankrd11_phenopacket.json` — 10 присутствующих и 7 исключённых HPO-признаков того же случая.

Этого случая нет среди 10 случаев организаторов. Это полусинтетический пример, а не геном пациента.

## Что должно получиться

| Шаг | Ожидаемый результат |
|---|---|
| Загрузка (нужен интернет) | 402 варианта: из кэша 400, онлайн 2; в списке случаев — «kbg_ankrd11_example (загружен)»; «пропущено строк: 4» |
| Анализ, тип наследования не известен | «Кандидат найден»: ANKRD11 `chr16:89279135:G:C`, балл ≈ 0.82 |
| Тип наследования AD | То же: ANKRD11 |
| Тип наследования AR | «Убедительного кандидата нет»: синдром KBG аутосомно-доминантный |
| Отчёт → «Ограничения» | Предупреждения о загруженном случае и о 4 пропущенных строках |

Без интернета загрузка этого файла завершится понятной ошибкой: 2 варианта не в кэше. Встроенные случаи продолжают работать офлайн.
