Профиль случая

Таблица — с колонками chrom, pos, ref, alt, genotype, как *_variants.tsv организаторов. Однонуклеотидные варианты с генотипом 0/1 или 1/1, до 5000 строк. Новые варианты аннотируются через Ensembl VEP и ClinVar — нужен интернет. Без файла фенотипа признаки можно добавить поиском ниже.

Профиль симптомов сокращён организаторами. Отсутствие термина не означает отсутствие симптома.

Фенотип

Для каждого признака укажите: есть, явно отсутствует или не учитывать.

Поиск по HPO ID или английскому названию

Если тип известен из родословной, гипотезы с другим типом наследования не выдаются как ответ.

Исходный профиль

Расчёт выполняется на этом компьютере. Внешние запросы (Ensembl VEP, ClinVar) делаются только при загрузке своего VCF и содержат лишь координаты вариантов.
